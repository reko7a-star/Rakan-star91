# Markdown Enhancer — VS Code Extension

Extension for VS Code Markdown Preview with GitHub-like styling, custom `markdown-it` containers, interactive spoilers and emoji.

## Syntax

```markdown
:::alert
Important information
:::

???spoiler "Click to reveal"
Hidden content
???

:fire:
```

## Run

```bash
npm install
npm run compile
```

Open the project in VS Code and press `F5` to launch an Extension Development Host. Then open a Markdown file and preview it.
